# 风格提示词图鉴

可浏览、搜索、一键复制的 AI 图片风格提示词分享站。

- 约 2094 条风格（含示例图）
- GitHub Pages：`https://mixx993.github.io/style-prompt-gallery/`

## 本地开发

```bash
npm install
python3 scripts/sync-images.py --styles /path/to/styles --catalog /path/to/catalog.json
npm run dev
```

## 构建

```bash
VITE_BASE=/style-prompt-gallery/ npm run build
```
